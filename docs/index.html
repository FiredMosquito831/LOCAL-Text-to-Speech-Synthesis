pytorch implemented

F5-TTS (PyTorch)

Zero-shot cloning with reference audio, configurable NFE steps and adapter checkpoints. This is the default and the most complete synthesis path.

  • VRAM floor1.5 GB min
  • Sample rate24000 Hz
  • Precisionfp32 · fp16 · int8
fish-speech scaffold

Fish Speech

Integration scaffold: the loading path is present, but the inference engine is not wired, so synthesis falls back to a placeholder tone. Treat it as unfinished.

  • VRAM floor2 GB min
  • Sample rate44100 Hz
  • Precisionfp32 · fp16 · int8 · int4
gpt-sovits implemented

GPT-SoVITS

Drives the external GPT-SoVITS package when installed. Without the package the backend logs a warning and returns a placeholder tone instead of failing loudly.

  • VRAM floor2 GB min
  • Sample rate32000 Hz
  • Precisionfp32 · fp16 · int8

Why local

Your microphone room, not someone's server room.

Private by construction

Text and reference audio are processed by local Python code. The application has no telemetry, analytics or cloud API client. Model weights are downloaded from Hugging Face only when needed.

A studio, not a demo

Waveform review, playback, voice-profile management, GPU monitoring, presets and a priority batch queue are part of the PyQt6 application.

Honest interfaces

The runtime layer is a real abstraction with capability metadata. Not every registered target synthesizes audio yet — this site says which ones do instead of promising a speedup.

The studio

Built around the loop: write, listen, revise.

The GUI exposes the same inference manager as the CLI, plus the supporting workflow.

Studio guide →
A

Text-to-speech panel

Editor with live character/word counts, language selection, backend switch, NFE steps, sampler, speed, seed and chunking controls.

B

Voice cloning

Drag in a reference clip, auto-transcribe it with faster-whisper when installed, score the sample and save a reusable speaker profile.

C

Profiles & adapters

SQLite-backed profiles with reference samples, quality scores and .vsp import/export. Adapter checkpoints are discovered from adapters/.

D

Batch queue

Priority queue with pause/resume/cancel, progress callbacks and optional per-job WAV output.

E

GPU monitor

NVML-based VRAM, utilization and temperature polling with a memory-manager view when CUDA is present.

F

Presets & precision

Four VRAM-oriented presets and a quantization catalogue. Conversion actions that are not implemented are marked as such in the UI.
