How a backend is selected

  1. 01
    CLI uses the literal --backend value (default f5-tts).
  2. 02
    GUI switches the inference manager's backend from the TTS/Backend tabs.
  3. 03
    Auto-selector scores registered backends by VRAM, platform and declared quality/speed. It is available as get_best_backend() but the GUI does not force it.
  4. 04
    InferenceManager resolves auto to CUDA when torch reports it, otherwise CPU.

SELECTION CASCADE

--backend → InferenceManager → backend class
--device auto → CUDA if available → CPU
--quantization → backend load → effective precision

The auto-selector can recommend TensorRT or vLLM on capable hardware even though those synthesis paths are incomplete. Treat its recommendation as a capability hint, not a promise.
