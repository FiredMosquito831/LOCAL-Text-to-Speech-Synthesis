Performance & limits

No benchmark theater.

This project does not publish latency, real-time factor or tokens-per-second numbers, because no benchmark was measured on a reference machine for this release. What follows are the limits and targets that are actually encoded in the source — clearly labelled as such.

Read this before quoting a number. The “speed multiplier”, “quality rating” and preset “expected RTF” values are design metadata used for backend selection and UI hints. They are not measurements and are not comparable across GPUs.

Memory behaviour

  • Lazy loading. Backends load on first synthesis, not at CLI start.
  • VRAM budget. AdaptiveMemoryManager defaults to a 5.5 GB budget with a 0.5 GB safety margin and optional LRU eviction.
  • Device resolution. --device auto picks CUDA only when torch.cuda.is_available() is true.
  • Unload is explicit. manager.unload_model() drops the backend and calls torch.cuda.empty_cache() when available.
  • CPU offload helpers exist in core/memory_manager.py, but the inference manager does not automatically move a loaded backend to CPU under pressure.

Audio path

  • Sample rates differ by backend: F5-TTS 24 kHz, GPT-SoVITS 32 kHz, Fish Speech declares 44.1 kHz.
  • Output is WAV via soundfile, using the sample rate returned by the backend.
  • No loudness normalization is applied by the CLI. The stitching helper can normalize when used directly.
  • Long text: the studio exposes chunking modes; the module provides sentence/character/token/paragraph strategies and crossfaded stitching. The CLI does not automatically enable LongTextSynthesizer.

Honest limits

What this release is not.

Not a turnkey GPU accelerator

ONNX, OpenVINO, TensorRT, DirectML, llama.cpp and vLLM are registered runtime scaffolds. Their synthesize() methods raise NotImplementedError. Do not expect acceleration from them.

Not a quality benchmark

There are no WER, speaker-similarity or MOS results in the repository. The site does not invent them, and neither should your project notes.

Not fully offline on first run

Model weights are fetched from Hugging Face when first needed. Once cached, synthesis runs locally. The app itself sends no telemetry.

Not every quantization flag is real

INT4 and GGUF are accepted by the CLI but have no effective F5-TTS path in this revision. The quantization manager's GGUF/GPTQ/AWQ conversions are placeholders.

Not a multilingual guarantee

The UI offers English, Romanian, Chinese and auto-detect. Auto-detection is a three-way character heuristic. Model-level language coverage depends on the weights and upstream package.

Not a Windows/Linux parity story

The pinned requirements target Windows/CUDA 12.1; the batch helpers are .bat files, DirectML is Windows-only, and vLLM is marked Linux-only.
