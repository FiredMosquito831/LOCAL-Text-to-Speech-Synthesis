About · security · license

A local tool should be auditable.

VoiceSynth Studio is a Python orchestration layer around open TTS models. This page describes what it does with your data, what it downloads, and what it deliberately does not do.

What this project is

A local-first TTS workstation: a backend interface, an inference manager, a PyQt6 studio and a CLI. It is a unified front end for external model families, not a new TTS model. The repository contains roughly {{ "{:,}".format(data.stats.python_lines) }} lines of Python across {{ data.stats.python_files }} files, with {{ data.stats.core_modules }} core modules.

The design goal is a predictable local workflow: choose a backend, provide a reference voice if you want cloning, synthesize, review the waveform, save audio. Batch and profile management are support features, not cloud services.

No authentication or server surface

The desktop app opens no HTTP port. It does not ship an API server. There are no credentials or API keys to manage.

Third-party model trust

Weights and model code are downloaded from Hugging Face and installed from upstream Git repositories. You are trusting those projects and the integrity of your network. Pin revisions where it matters to you.

File paths are user-supplied

Reference audio, text files, adapters and output paths come from the user. The app writes where you point it; it does not sandbox paths.

Placeholder fallbacks are intentional

Some backends return tones instead of failing. This is a usability choice, not a security boundary; check logs if audio is unexpected.

Voice cloning and consent. Clone only voices you have permission to use. Synthetic speech can be mistaken for a real person. The project does not add watermarks or provenance metadata to generated audio, and the MIT license grants no rights to third-party voices or model weights.

Reporting a vulnerability

Open a private security advisory on GitHub, or contact the maintainer via the repository. Do not publish exploitable details before a fix is available. See SECURITY.md for scope and expectations.

License
